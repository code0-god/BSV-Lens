# ADR G5-004: Contributors are not cone-wide source causes

Status: accepted for the explicitly authorized G5 implementation.

Stock G3 evidence proves source ranges, method contracts and ordered
connectivity. Instrumented evidence proves only particular recorded known
contributors. Current complete origin sets remain unestablished.

G5 calls existing G3 public queries and displays their actual target,
occurrence, revision, provider, mapping scope and limitations. Neither
adjacency, common names, cell type, nearby source lines nor cone membership
propagates a contributor claim to another object.

Unmapped hardware remains useful and inspectable. Original BSV is opened only
through a verified reference or explicit candidate; generated RTL evidence
remains generated. Source-only helper analysis does not mint hardware.

Query/semantics coverage and existing source-origin populations remain
separate in reports and UI. More displayed links are not improved origin
coverage.
