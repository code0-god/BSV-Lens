## Changed product contract

1. Opening the experimental command explicitly authorizes bounded static BSV
   discovery inside the chosen current workspace folder. Activation authorizes
   neither discovery nor compiler/task execution. External roots remain explicit.
2. Source inventory, dirty buffers, exclusions and partial limits are distinct.
   Saved-source parsing is coalesced after changes; an immutable prior build is
   retained until a validated replacement can be committed.
3. BSV overview prioritizes the current boundary, direct child instances,
   storage, direct interface groups and verified summary relations. Canonical
   facts remain intact. Exact family/owner/interface membership determines
   summaries; selection discloses the original members and source evidence.
4. A valid BSV structure may disclose an explicitly deferred secondary relation.
   Identity/authority/structure failures never receive that fallback. RTL routing
   and canonical net membership remain strict. Normal required AQuA scenes must
   display real summary routes without treating all-deferred blocks as success.
5. Selectors, header, canvas, Inspector and native source authority describe one
   committed visit. Pending and failed targets are separate. Retry and diagnostic
   details preserve the exact failure without making raw router IDs primary copy.
6. A module body/title enters once; information actions inspect; storage,
   interfaces and connections disclose evidence. Keyboard has equivalent actions.
   Source-only analysis is usable without RTL and explains the optional connection
   once. Native major controls/messages support Korean with English fallback.
